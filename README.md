# 007 Vidensportal

Interaktiv vidensportal om James Bond, filmhistorie, karakterudvikling og **007 First Light**.

Projektet er lavet af Simon og Lucas til Kommunikation & IT A. Målgruppen er 40–60-årige etablerede James Bond-fans.

## Indhold

- Agentprofil og karakteranalyse
- Filmoversigt og filmsagsmapper
- Interaktiv tidslinje og periodeprofiler
- 007 First Light og spilanalyse
- Sammenligningsværktøj
- Efterretningsrapport og kildearkiv
- Separat designmanual

Hjemmesiden består af almindelig HTML, CSS og JavaScript og kan afvikles direkte med GitHub Pages.
